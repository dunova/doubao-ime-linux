Experimental source prerelease of the unofficial Fcitx 5 bridge, now targeting
**DoubaoIME Windows 0.9.2.7**.

## Changes since 0.1.0-rc.1

- **Live dictation previews:** provisional speech appears in Fcitx preedit and
  is revised while recording; only the final result is committed. Right Alt
  supports hold-to-talk, and Right Alt+Space supports hands-free dictation.
- **Optional smart text organization:** reuse the official Windows client and
  networking SDK in a separate Wine runtime. Explicit time, date and quantity
  corrections are resolved across the passage before cloud organization.
  Checks reject observable losses of numbers, negations, emphasis, quoted
  content and explicit recipient names. Failures fall back to the accepted
  transcript; cancellation and focus changes prevent late text delivery (#2).
- **Engine upgrade:** support the fixed official version 0.9.2.7, including
  verified Pinyin, double Pinyin, Wubi and simplified/traditional input options.
- **Keyboard UI:** fix candidate paging, add a settings tray action and distinct
  icons, and follow the Fcitx UI's candidate-layout preference instead of forcing
  vertical candidates (#4). Thanks to @dunova for the layout fix and report.
- **Reliability:** retain bounded audio captured before ASR connects, provide
  opt-in IPv4 voice connections and diagnostics, and wait for a live test
  socket instead of a leftover file (#3). Document the one-command/one-response
  connection contract.

The upstream Fcitx 5.1.23 classic UI defaults to horizontal candidates. Following
its preference can therefore change the previous forced vertical layout even
when the user has not explicitly configured it; distribution defaults may vary.

## Setup and compatibility

Follow the versioned [English README](https://github.com/royess/doubao-ime-linux/blob/v0.1.0-rc.2/README.md)
or [Chinese README](https://github.com/royess/doubao-ime-linux/blob/v0.1.0-rc.2/README.zh-CN.md).
The official installer must be supplied separately. An existing setup using
0.9.0.0 needs the supported 0.9.2.7 components prepared before using this version.

Voice input still requires a separately supplied ASR adapter. Smart organization
also requires `python3 scripts/prepare_organize.py` and
`doubao-voice organize-on`; `doubao-voice organize-off` retains literal
transcription. It sends final speech text to Doubao's official organization
service. Initialization overlaps recording; after the final ASR result,
organization waits at most 25 seconds before falling back. See the
[voice documentation](https://github.com/royess/doubao-ime-linux/blob/v0.1.0-rc.2/docs/voice.md).

Windows smart undo/restore-original remains unsupported. Terminals and clients
without multiline capability receive flattened paragraphs. Ambiguous corrections
remain conservative; content checks do not prove semantic equivalence for every
utterance. Account synchronization, complete Windows settings parity and
long-running stability remain unverified.

## Validation

- 62 unit tests passed locally.
- The real official keyboard engine passed all 11 RPC checks with a stale test
  socket, then all 11 again with a clean endpoint.
- Nine artificial samples passed against the actual official organization
  service, covering corrections, comparisons, negations, emphasis, fillers and
  a longer passage. A separate Fcitx/GTK run passed 61 checks, including official
  organization and cancellation.
- The merged layout fix passed full and keyboard-only builds and 57 isolated
  Fcitx/GTK fixture checks.
- Publishing is gated on GCC and Clang CI, including native/Windows-helper
  builds, unit tests, fixture integration, installation and reproducible archives.

Live official-service checks were local and separate from CI; the current
release has no new human-microphone regression. These results do not establish
complete Hyprland/Wayland coverage. See the
[validation record](https://github.com/royess/doubao-ime-linux/blob/v0.1.0-rc.2/docs/validation.md).

## Download and verify

Download `doubao-ime-linux-0.1.0-rc.2.tar.gz` and `SHA256SUMS` into the same directory:

```sh
sha256sum -c SHA256SUMS
tar -xzf doubao-ime-linux-0.1.0-rc.2.tar.gz
```

The assets contain bridge source, build tools, tests and documentation. Official
EXE/DLL files, Wine, fonts, dictionaries, credentials, recordings and the external
ASR adapter are excluded. Build and prepare the runtime using the README.
